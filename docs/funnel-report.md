# Funnel report

The local counter has no upstream pull-request window. These are the fields `forge report` prints. The values are `no upstream` rather than counts from a GitHub window. `repo` is the sample's `local/counter`.

```
repo local/counter
limit no upstream
order no upstream
considered no upstream
not_merged no upstream
revert no upstream
too_many_files no upstream
too_many_lines no upstream
unknown_size no upstream
binary no upstream
lockfile no upstream
docs_only no upstream
missing_source_or_test no upstream
no_linked_issue no upstream
accepted no upstream
older_prs_cut_off no upstream
```
